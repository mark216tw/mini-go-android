# mini圍棋 使用指南

本文件說明 mini圍棋的操作流程、對弈功能、計分方式與常見問題。

> 目前 GitHub Release 為 `1.0.0-prerelease` 測試版，使用 Debug 金鑰簽署，僅供測試安裝。

## 1. 安裝與啟動

1. 下載 `app-prerelease.apk`。
2. 在 Android 設定中允許安裝未知來源 App。
3. 安裝並開啟「mini圍棋」。
4. 第一次進入時，首頁會顯示「第一次下圍棋？」提示，可選擇查看教學或略過。

系統需求：Android 8.0（API 26）以上。

## 2. 首頁

首頁提供以下入口：

| 項目 | 說明 |
| --- | --- |
| 續玩 | 若有一局未結束的對局，顯示棋盤大小、模式、難度與手數，可直接繼續。 |
| 快速開始 | 使用設定中的預設模式、執子、棋盤與難度直接開新局。 |
| 開始對弈 | 進入對弈設定，自行選擇棋盤、模式、難度與執子。 |
| 規則教學 | 開啟 8 頁圖文教學。 |
| 更多（右上角） | 進入設定與關於。 |

### 捨棄續玩存檔

1. 在續玩卡下方點「捨棄」。
2. 確認後會刪除目前存檔，無法復原。
3. 若已有存檔時使用「快速開始」，也會先詢問是否覆蓋。

## 3. 對弈設定

- **棋盤大小**：9 路（推薦入門）或 13 路。
- **對弈模式**：與電腦對弈、雙人對弈。
- **電腦難度**：
  - 入門：輕鬆練習，較多隨機性。
  - 初級：會優先提子、避免明顯失誤。
  - 中級：加入基本形勢與一手前瞻，思考時間較長。
- **我的執子**：黑棋先手或白棋後手。

按「開始」進入對局。

## 4. 對弈畫面

### 狀態列

顯示：

- 目前輪到黑棋或白棋。
- 電腦思考中或計分中。
- 目前手數與最後一手座標（例如 D4）。
- 黑提／白提數量。
- 貼目 6.5。
- 提示座標（使用提示後）。

### 棋盤操作

- 點擊交叉點落子。
- 最後一手以紅色圓環標記。
- 提示以藍色圓環標記，並在狀態列顯示建議座標。
- 打劫、自殺手或已有棋子時，會以 Snackbar 說明原因。

### 操作按鈕

| 按鈕 | 功能 |
| --- | --- |
| 悔棋 | 回到上一手；對電腦對弈時會一次退回到自己的回合。 |
| 提示 | 由 AI 計算一個建議點，按鈕顯示「計算中」時請稍候。 |
| 虛手 | 跳過本手；雙方連續虛手後進入計分。 |
| 認輸 | 確認後直接結束本局，對方獲勝。 |

### 右上角更多選單

- **重新開始**：保留目前設定，開一局新棋；需確認。
- **規則教學**：開啟教學，返回後會回到原本的對局。
- **結束對弈**：強制結束並刪除本局存檔，回到首頁；需確認。

### 離開對局

按返回鍵或左上角返回時：

- 對局進行中：詢問是否離開；確認後會先寫入最新進度。
- 對局已結束：直接回到首頁。

離開後可從首頁「續玩」繼續。

## 5. 規則教學

規則教學共 8 頁：

1. 棋盤：交叉點、9／13 路、星位與座標。
2. 氣：棋子的生命線。
3. 提子：沒有氣時移除棋子。
4. 打吃：只剩最後一口氣。
5. 禁入點：自殺手與例外。
6. 打劫：禁止立即回提。
7. 虛手：跳過一手與連續虛手結束。
8. 勝負判定：中國規則數子法、貼目與死子。

使用「上一頁／下一頁」瀏覽，最後一頁按「完成」返回。

## 6. 計分流程

1. 雙方連續虛手。
2. 進入計分畫面，狀態列顯示「計分中」。
3. 點擊棋盤上已無法做活的棋組，標記為死子；再次點擊可取消。
4. 可用「清除標記」一次取消所有死子。
5. 分數預覽會顯示：
   - 黑棋：棋子數 ＋ 地數。
   - 白棋：棋子數 ＋ 地數。
   - 中立點數。
   - 合計分數（白棋含 6.5 目貼目）。
6. 按「確認計分」顯示結果；按「返回對弈」可取消計分繼續下。

計分採中國規則數子法：

```text
黑棋總分 = 黑棋棋子數 + 黑棋圍空
白棋總分 = 白棋棋子數 + 白棋圍空 + 6.5
```

## 7. 對局結果

結果對話框顯示：

- 勝方、合計分數與勝差。
- 黑棋／白棋子數。
- 白棋貼目。
- 認輸時顯示「某某勝（對方認輸）」。

可選擇：

- **再來一局**：沿用目前設定開新局。
- **查看棋盤**：關閉結果框，檢視終局盤面。
- **回到首頁**：儲存目前結果後回首頁。

查看棋盤後，可用棋盤下方的「查看結果」重新開啟結果。

## 8. 設定

從首頁右上角「更多」→「設定」進入。

- **顯示模式**：跟隨系統、淺色、深色。
- **動態配色**：Android 12 以上可依系統桌布調整主題色。
- **顯示座標**：棋盤外圍顯示字母與數字。
- **落子震動**：落子時提供觸覺回饋。
- **預設對弈模式**：快速開始與對弈設定的預設值。
- **預設棋盤**：9 路或 13 路。
- **預設難度**：入門、初級、中級。
- **預設執子**：黑棋或白棋。

設定會即時生效並自動保存。

## 9. 續玩與結束的差異

| 操作 | 是否保留進度 |
| --- | --- |
| 返回鍵／左上角返回 | 是，會先存檔。 |
| 右上角「結束對弈」 | 否，會刪除存檔。 |
| 右上角「重新開始」 | 否，直接開始新局。 |
| 首頁「捨棄」 | 否，刪除存檔。 |

## 10. 常見問題

### 點了棋盤卻沒有落子

可能原因：

- 目前是電腦回合，請等待電腦落子。
- 該點已有棋子。
- 該點是自殺手或打劫禁入點，畫面會顯示原因。
- 目前處於計分模式，點擊是在標記死子。

### 提示按鈕顯示「計算中」

AI 正在計算建議點，完成後會顯示藍色圓環與座標。

### 無法悔棋

- 已經沒有可回溯的歷史。
- 悔棋最多保留最近 80 手。
- 對局已結束或正在計分時不提供悔棋。

### 電腦都沒有落子

電腦思考時狀態列會顯示「電腦思考中…」。若電腦選擇虛手，會顯示「電腦虛手」提示。

### 續玩卡不見了

可能已按「結束對弈」「重新開始」或「捨棄」，這些操作會刪除存檔。對局正常結束後也不會再顯示續玩。

### 為什麼結果和我算的不一樣

請確認是否已正確標記死子。本 App 採中國規則數子法，白棋貼 6.5 目；雙活或雙方交界的中立空點不計分。

## 11. 已知限制

- 僅支援 9 路與 13 路。
- AI 為啟發式引擎，非職棋等級。
- 死子需手動標記。
- 無線上對戰、帳號、雲端同步與觀戰功能。
- 悔棋最多回溯 80 手。
- `prerelease` APK 使用 Debug 金鑰簽署，僅供測試。
